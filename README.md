# Order Processing System

A Python-based Order Processing System demonstrating the practical use of **Iterators and Generators** for processing order data sequentially.

## Features

- Process orders using a custom iterator
- Process orders using a generator
- Find high-value orders
- Generate order amounts one at a time
- Demonstrate sequential data processing

## Technologies Used

- Python
- Iterators
- Generators
- Classes
- `__iter__()`
- `__next__()`
- `yield`
- Lists
- Dictionaries
- Loops
- Conditional Statements
